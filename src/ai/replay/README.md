# Replay: reglas

Regla que ya se rompió dos veces en esta sesión (y1iz5l antes, igmt9z ahora):
un fixture es una grabación real, nunca se edita el texto de modelResponses
para que una aserción pase. Si una aserción prueba algo que no le toca a
esta fase, se acota la aserción o se separa en otro turno de expectativa —
nunca se toca lo que el modelo dijo.
